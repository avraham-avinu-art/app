# Night Screen

A minimal Android full-screen clock designed as a calm screen-saver-style display.

Features:
- Black background with white typography.
- Large live 24-hour clock.
- Gregorian date.
- Hebrew calendar date.
- Minimal integrated player surface.
- Immersive full-screen mode and keep-screen-on behavior.

Build:
```
./gradlew :app:assembleRelease
```

The release APK is produced at:
`app/build/outputs/apk/release/app-release.apk`
